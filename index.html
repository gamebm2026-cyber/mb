Start a Linux desktop from mb.ipynb

Open the notebook in a Codespace or VS Code, then run the cells from top to bottom. The notebook installs a full XFCE desktop, a browser, and a remote viewer you can open from any tab.

Steps

  1. Open the notebook Click mb.ipynb in the explorer on the left.
  2. Run Cell 1 to install dependencies This takes several minutes and needs administrator access.
  3. Run Cells 2 to 5 Installs the browser, starts the virtual display and desktop, then starts the remote viewer.
  4. Run Cell 6 for a public link (optional) Creates a tunnel so you can open the desktop from another device.
  5. Open the desktop Open the remote viewer link from the Ports panel once Cell 5 has finished.

Notebook sections

Cell 1: Install dependencies

Installs the desktop, display server, and remote viewer packages.

Cell 2: Install Brave Browser

Adds the Brave browser to the desktop.

Cell 3: Start virtual display and XFCE

Starts the invisible screen and the XFCE desktop running on it.

Cell 4: Start VNC server

Lets the remote viewer connect to the desktop screen.

Cell 5: Start noVNC

Serves the desktop in a browser tab.

Cell 6: Public tunnel (optional)

Creates a public web link to the desktop.

Cell 8: Launch Brave on the desktop

Opens the browser inside the desktop.
